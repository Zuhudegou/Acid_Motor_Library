# Acid_Motor_Library
## 简要说明
此文档用于理解我所开发的此版电机驱动库
本电机控制库 基于 https://github.com/Sguan-ZhouQing 所开发的SguanFOC_library进行二次开发
添加了针对fdcan的MIT控制方法
并把串口功能简化为 进行模式选择 
将控制包 仅通过can接收
